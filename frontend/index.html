Overview Competitions Requirements Rulebook

Every competition solved, with receipts.

An engine that keeps one agent permanently briefed on each Kaggle competition (problem statement, evaluation metric, datasets, profile) and triggers OpenCode to write the solution notebook every time it is asked — under a versioned rulebook, gated on a score target, and leaving an artifact trail for every number it claims.

No competition is dropped: the cycle runs every 24 hours (locally or through GitHub Actions), and a run only counts when the out-of-fold score is measured, recorded and matched against the gate.
