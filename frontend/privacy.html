Privacy

This site is a static dashboard. It has no accounts, no forms, no cookies and no analytics, so there is little about you for it to collect. This page states exactly what it does serve and where it sends you.

Back to the dashboard Terms and conditions

Data this site collects

Nothing

The site sets no cookies of its own, runs no analytics or tracking scripts, and has no accounts, logins, forms or newsletter boxes. Nothing is submitted through the site, because there is nothing to submit to.

What it serves

Static files and one public JSON document

Every page is a static file: HTML, one stylesheet and one script. The only dynamic request is data/dashboard.json from this same site. That file is generated by the engine and contains competition names and slugs, metric values, run timestamps and the rulebook version. It describes the repository's own automated activity, not its visitors.

Credentials never appear here

Kaggle credentials stay on the machine that runs the engine and never ship with the dashboard (rule R12). The deployed site contains no secrets, no personal data and no private competition material.

Third parties

Hosting

Files are served by Vercel at kaggle-solutions-dashboard.vercel.app. Like any web host, Vercel processes standard server logs (IP address, user agent, requested path) for operations and abuse prevention, under Vercel's own privacy policy.

External links

Links lead to kaggle.com and github.com. Once you follow one, that site's privacy policy applies. This dashboard does not control what those sites collect.

Changes and contact

Versioned like everything else

This policy is part of the site's source. The current text always lives at privacy.html in the repository, and its history is visible in git.

Questions

Open an issue on the GitHub repository. There is no contact form, because there is no data to request.
